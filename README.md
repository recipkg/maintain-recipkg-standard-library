# maintain-recipkg-standard-library

维护 Recipkg 标准库的分类、候选筛选、独立配方仓库、递归依赖与目录发布。

Read [SKILL.md](SKILL.md) for the canonical workflow and [SKILL.zh-CN.md](SKILL.zh-CN.md) for the aligned Simplified Chinese version. This is a standalone project skill consumed as a pinned Git submodule by Recipkg projects.

## Install as a project skill

```sh
git submodule add https://github.com/recipkg/maintain-recipkg-standard-library.git .agents/skills/maintain-recipkg-standard-library
git submodule update --init --recursive
```
